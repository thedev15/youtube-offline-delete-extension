YouTube Offline Remove

Removal delegates to YouTube's native control or a supported Downloads-sidebar menu. No helper tab, iframe, download-page navigation, guessed API calls or direct storage deletion.

Experimental offline adapter: “Check native control” prepares YouTube's own renderer without clicking it. If the native removal label is unavailable, stop. Live offline deletion and next playback still need verification with a disposable download you explicitly confirm removing. Native labels are UI evidence, not proof of deleted media bytes.

The experimental native-control adapter currently recognizes English labels only. The fields below configure the legacy sidebar-menu adapter. For another YouTube language, enter the exact displayed labels, one per line. Matching ignores case and extra spaces. Do not add generic “Delete” or “Remove” labels.

This never skips a video when removal fails. If there is no next downloaded video, playback stays on the current page.

Maximum 12 labels per field, 100 characters each. Every removal requires confirmation; this cannot be disabled.

Privacy and scope

No analytics, account credentials, cookies, video files, or private YouTube endpoints. Only these settings use browser sync storage. Your browser provider may sync them if you enable browser sync. The extension does not provide or bypass YouTube Premium downloads.
